# DocuChat AI

A Retrieval-Augmented Generation (RAG) chatbot that answers questions from PDF documents using LangChain, ChromaDB, Hugging Face embeddings, and Ollama.

## Features

- PDF document ingestion
- Semantic search with ChromaDB
- Retrieval-Augmented Generation (RAG)
- Local LLM using Ollama (Llama 3.2)
- Source citations

## Tech Stack

- Python
- LangChain
- ChromaDB
- Hugging Face Embeddings
- Ollama
- Llama 3.2

## Installation

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```
